# Project log

Decisions made and why, newest first. Open work is tracked in [GitHub issues](https://github.com/Hive-Society-Improv/Hive-Society-Website/issues) (grouped by [milestone](https://github.com/Hive-Society-Improv/Hive-Society-Website/milestones)); finished work is in the merged PRs.
When a decision changes conventions, commands, or layout, update [AGENTS.md](../AGENTS.md) and whichever doc describes it (README, [RUNBOOK](RUNBOOK.md), [ARCHITECTURE](ARCHITECTURE.md)) in the same change.

| 2026-10-08 | **Open work moves to GitHub issues** (types Task/Bug/Feature; labels `area: …`, `decision needed`, `on hold`, `blocked`; milestones Astro migration, CMS, Calendar). This log keeps decisions only; the Done list is dropped (merged PR titles and release-please's changelog record finished work). `.gitattributes` sets `merge=union` on this file | Every PR added lines at the top of the TODO and Done lists, so parallel PRs conflicted on almost every merge.
